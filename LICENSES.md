# Simulation authorship

PhET: NO embeds — originals only (decision 16 Oct 2026)

All simulations in the FIT simulation library are original FIT work. The models,
interaction code, illustrations, game shell and synthesised sounds are authored
for FIT. No third-party simulation code, branded simulator assets or external
simulation embeds are included.

The library uses the site's existing application dependencies under their
respective licences. This statement does not relicense those dependencies or
claim ownership of the mathematical and scientific concepts being taught.
