The maths

Trapezium rule: I ≈ h[½y₀ + y₁ + ⋯ + yₙ₋₁ + ½yₙ]. It integrates the straight-line interpolation between adjacent measured samples.

Composite Simpson's ⅓ rule: I ≈ (h/3)[y₀ + yₙ + 4(y₁ + y₃ + ⋯) + 2(y₂ + y₄ + ⋯)]. It requires equally spaced samples and an even number of intervals.

The sensor values displayed in the table, rounded to 3 decimal places, are the authoritative data for computing a numerical answer.

For method comparisons, an ideal continuous calibration signal is used as reference. Random measurement noise means Simpson's rule is not automatically more accurate.

Velocity (m/s) × seconds gives metres. Power (kW) × seconds gives kJ. Flow (L/min) × minutes gives litres.
