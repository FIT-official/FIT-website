How a repeat works

A repeat block can make several moves using fewer blocks.

Build your programme

Tap a block to pick it, then add a command after it. Tap a repeat block before adding commands inside it. Use ↑ and ↓ to reorder blocks, or drag them.

The idea

Commands run in order. A repeat runs its inside commands several times. The robot must stay on the safe path and reach the star. A repeat counts as one block, but its commands still move the robot.
