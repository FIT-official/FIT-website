The maths

Threshold: output = 1 when pixel ≥ T; otherwise 0.

True convolution: output(y,x) = sum of input(y+i,x+j) times the kernel flipped in both directions.

Block downsampling: new pixel = sum of block values divided by the number of pixels. New pixel width = old width × block factor.

Assumption: pixels are uniformly spaced; block averages represent each output pixel.
