The physics

Ohm's law: V = IR, with V in volts, I in amperes and R in ohms.

Series: R_total = R₁ + R₂ + R₃. The same current passes through each resistor.

Parallel: 1/R_total = 1/R₁ + 1/R₂ + 1/R₃. Each branch has the same p.d.

Power: P = VI = V²/R. For ideal resistors, the I–V line passes through the origin.
