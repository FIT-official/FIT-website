Computed values

Area uses the number of foreground pixels multiplied by the square of pixel width.

Concept: a mixed pixel can contain several endmembers.

The maths

BT.601 luma: Y = 0.299R + 0.587G + 0.114B. R, G and B are channel levels; Y uses the same level scale.

Linear mixture: s = M a. For a 2 × 2 matrix, solve a = M⁻¹s. When the determinant is near zero, the endmembers are indistinguishable numerically.

Ground area: A = N f², where N is foreground pixel count and f is pixel width in metres.

Assumption: pixels are square and the classified scene represents the mapped ground surface.
