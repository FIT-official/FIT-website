The maths

Assume independent defects with constant defect probability p. This is a binomial approximation to large-lot sampling.

Let X be the defects in n inspected parts: X ~ B(n,p).

Probability of accepting a batch: Pₐ(p) = P(X ≤ c) = Σ from x = 0 to c of C(n,x)pˣ(1−p)ⁿ⁻ˣ.

Probability of rejecting a batch: Pᵣ(p) = 1 − Pₐ(p).

An OC curve plots Pₐ against the true percentage of defective parts. It is calculated exactly under the binomial model using recurrence, without Monte Carlo error.
